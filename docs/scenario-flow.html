能力边界与已知缺口

A · 后端不可强制：按设计拒绝，而非静默放行

Firecracker microVM 后端编译通过的骨架；需 Linux + /dev/kvm，本机不可用
egress 白名单强制容器后端无法强制 → 返回 501 而非假装
磁盘配额强制overlayfs 上无法强制 → 返回 501
user namespace 身份分离本机 userns=off：容器内 uid 0 即宿主 uid 0

B · 本版未提供的能力

Python / TypeScript SDK只有 HTTP + sbxctl CLI
多节点 / HA单机；无选主、无跨节点调度
计量计费无用量计量与账单
GPU 沙箱不支持

C · 已知实现缺口（不是设计取舍）

平台默认速率不可配置硬编码，无配置键；全平台调整须逐租户下发
PATCH 租户配额是整对象替换漏传 rates 会静默回退平台默认 —— 本场景已复现
